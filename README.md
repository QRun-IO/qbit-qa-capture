# QBit QA Capture

Optional, provider-pluggable QA bug capture for QQQ applications. [Jam](https://jam.dev) is the first
provider. QA capture settings, audiences, sanitizer rules and QA reports are standard QQQ tables.

Design: [docs/DESIGN.md](docs/DESIGN.md). The implementation lands in the first feature pull request.

## Build

```bash
./mvnw verify
```
